# Case Study - Analyzing Fantasy Football Media

This repository contains the case study, supplemental data, and reference materials necessary to complete the Case Study.

## Important Information

The attached PDF documents include the Case Study prompt and Hook document as well as a Rubric to follow in order to meet all requirements successfully.

- **CS3_CaseStudy.pdf** - The case study prompt and deliverable requirements
- **CS3_Hook.pdf** - Additional context and guidance for the case study
- **CS3_Rubric.pdf** - The grading rubric for evaluating your work

## Data

### /Materials/Data

The necessary data is located in the "Data" folder under Materials and includes:

- **fantasy_dataset_final.csv** - The cleaned dataset to be used for your model
- **text_dataset.json** - Additional text data for analysis
- **CS3_DataDictionary.pdf** - Data dictionary describing all variables and their descriptions

## Reference Materials 
### /Materials/Technical References

The "Technical References" folder contains helpful resources including:

- **eda_plots.ipynb** - Jupyter notebook with exploratory data analysis examples and visualization techniques
- **sentiment_analysis.py** - Reference Python script for sentiment analysis methods and implementations
- **Readings/** - Additional reading materials and contextual resources for the case study topic

The "Readings" folder contains sample articles to provide a sample of the text data referenced in the case study
